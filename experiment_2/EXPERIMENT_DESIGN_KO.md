# 실험 2 · LessMark 비교 실험 설계

**7개 모델·데이터셋 조건 × 6개 삽입 방법 × 5개 강도 = 210개 후보.** 각 조건에서 같은 원본을 분류는 추가 200에포크(140,400업데이트), 생성은 추가 2,048업데이트 학습한다. 학습형 네 방법은 이 기간에 워터마크를 학습하고, 직접 삽입 두 방법은 과제만 학습한 종료 모델의 복사본에 신호를 더한다. 조합마다 종료 시점의 정상 복호 BER가 가장 낮은 강도를 선택하고, 동률이면 가장 큰 강도를 택한다. 모든 후보의 분류 정확도 또는 생성 출력 차이를 미삽입 대조군과 비교한다. 선정한 모델은 삽입 직후의 품질을 테스트하고, 각각 가지치기·양자화·다른 도메인 미세조정(FT)을 거친 뒤 같은 메시지와 품질을 다시 평가한다. 2026년 11월 25일 기준 본실험 측정 결과는 없다. ## 1. 연구 질문과 실험 단위

1. 원래 도메인에서 같은 추가 과제 학습량을 제공했을 때, 방법과 강도에 따라 256비트 복호 오류와 미삽입 모델 대비 출력 차이는 얼마나 달라지는가?
2. 선정한 워터마크 모델을 가지치기하거나 양자화하거나 다른 도메인에서 미세조정하면 원래 메시지의 BER는 어떻게 변하는가? 같은 변형을 받은 미삽입 대조군과 비교한 분류 정확도 또는 생성 출력 차이는 얼마인가?

분류 2조건(CIFAR-100의 MobileNetV3-Large, ResNet18)과 생성 5조건(ImageNet·Caltech256 각각의 U-Net, SiT-B/2 및 FFHQ의 StyleSwin-256)에 여섯 방법을 적용한다. 아키텍처는 다섯 종류이며 U-Net과 SiT-B/2를 각각 두 도메인에서 평가하므로 원본 가중치는 일곱 개다. 각 원본에 VanillaMark, GreedyMark, NeuralMark, DeepMark, TATOOED, LessMark를 적용해 **42개 조합**을 만들고, 조합마다 다섯 강도를 독립적으로 시험한다. 분류는 12조합·60후보, 생성은 30조합·150후보로, 총 **210후보**다. 모든 후보와 최종 복호의 정답은 수신자 ID 292 한 명의 같은 메시지다. 조합마다 워터마크 모델 하나씩, **총 42개 선정이 목표**다. 실제 선정 수와 복호 실패로 미선정된 수를 함께 보고한다.

| 기호 | 실제 모델 | 비교하는 시점 |
| --- | --- | --- |
| C₀ | 과제 학습을 마친 미삽입 원본 | 조건별 추가 학습을 시작하는 시점 |
| `C_T` | C₀에서 원래 도메인 과제만 고정 기간 T만큼 추가 학습한 미삽입 모델 | 같은 조건의 여섯 방법과 모든 강도가 공유하는 종료 대조군이자 직접 삽입에 쓰는 모델 |
| `W_T` | 학습형은 C₀에서 과제·워터마크 손실을 함께 T만큼 적용한 모델. 직접 삽입은 `C_T`의 복사본에 한 번 신호를 더한 모델 | 다섯 후보 각각을 복호하고 `C_T`와 검증 품질 비교 |
| 가지치기·양자화 후 W와 C | 선정한 `W_T`와 대응 `C_T`를 복사해 양쪽에 같은 종류·수준의 변형을 적용한 쌍 | 변형 후 W의 메시지 복원과 원래 도메인의 쌍별 품질 비교 |
| W-FT, clean-FT | 선정한 `W_T`와 같은 `C_T`를 각각 새 도메인에서 미세조정(FT)한 모델 | FT 후 메시지 복원과 쌍별 성능 비교 |

## 4. 메시지와 삽입·복호 방법

### 256비트 공통 메시지

수신자 336명의 균형 불완전 블록 설계(BIBD) 코드표에서 사전 무작위 평가 목록의 첫 번째인 **ID 292**를 고정한다. 256자리 중 0과 1은 각각 128개다. 첫 비트부터 네 개씩 묶은 실제 삽입 순서는 다음 16진수다. 맨 앞 0을 유지하고 각 자리의 가장 높은 비트부터 읽는다.

```text
0bf6401f4dffb413c1a1fdff6950d0575de0e2b892c0c3f596121209a1ff3e05
```

(64,4,1) BIBD의 64개 점과 336개 블록을 쓴다. 4원 유한체 GF(4)의 3차원 공간에서 점을 사전순으로 번호 매긴다. 네 점을 지나는 각 직선을 하나의 블록으로 삼아 점 번호 네 개를 정렬하고, 블록들을 사전순으로 나열한 0부터의 행 번호를 수신자 ID로 쓴다. 수신자마다 블록의 네 점은 0, 나머지 60점은 1로 두고, 뒤에 0이 124개, 1이 68개인 192자리를 붙인다. NumPy PCG64의 채움 시드 20261122로 수신자 ID 순서대로 뒷부분을 섞고 시드 20261123의 공통 순열로 256개 물리 위치를 정한다. 수신자 목록 순열 시드는 20261124다. 서로 다른 두 블록은 최대 한 점에서 만나므로 비트별 AND를 정확히 복원하는 조건에서 최대 세 참여자를 구분할 수 있다. 무잡음 부호 점검에서는 336개 모두 LDPC 부호 복원에 성공했고, 32명에서 뽑은 2인 496조합과 3인 4,960조합을 식별했다. 이 점검은 부호 기호에 대한 검증이다. 가중치에서 측정하는 결과의 범위는 수신자 292의 이 한 메시지다. 다른 ID의 메시지별 편차와 실제 모델 공모에 대한 강건성은 별도로 측정해야 한다. ### 여섯 방법이 쓰고 읽는 값

아래에서 m은 공통 0·1 배열, b=2m−1은 ±1 배열이다. 같은 방법·조건의 다섯 후보에는 동일한 목표, 키, 가중치 위치와 복호기를 사용한다. 복호기는 모델 가중치와 필요한 키·기저만 받아 비트를 출력하고, 정답 m은 채점 단계에 사용한다.

| 방법 | 가중치 삽입과 강도의 의미 | 복호 |
| --- | --- | --- |
| VanillaMark | 선택 가중치를 출력 축으로 평균하고 키 행렬로 투영한다. 256개 목표 m의 비트별 이진 교차엔트로피 합에 λ를 곱한다. | 투영 점수의 sigmoid가 0.5를 넘으면 1 |
| GreedyMark | 선택 가중치를 비트별 그룹(폭 253)으로 집계하고 절댓값이 작은 절반을 0으로 만들어 평균 잔차를 구한다. μ=0.1의 힌지 손실 합에 λ를 곱한다. 저작권 서명의 목표 부호를 b로 바꾼다. | 잔차 부호가 양수이면 1이며 한 좌표라도 0이면 판정 불가 |
| NeuralMark | 512×256 투영 키의 SHAKE-256 해시로 가중치를 4회 필터링하고 512개로 풀링한 후 투영한다. 필터는 유지하고 비트별 평균 이진 교차엔트로피의 목표를 m으로 둔다. 강도는 λ다. | 키 투영 점수의 sigmoid가 0.5를 넘으면 1. 공통 메시지의 일치율·BER를 채점 |
| DeepMark | 투영 행렬 X로 읽은 가중치와 직교행렬 U로 변환한 목표 지문 Ub의 평균제곱오차에 λ를 곱한다. | 지문에 U의 전치를 적용한 좌표가 구현 임계값 0.85를 넘으면 1 |

학습형 네 방법의 가중치 판독 위치는 MobileNet의 `features.16.0.weight`, ResNet18의 `layer4.1.conv2.weight`, U-Net의 `output_blocks.17.0.out_layers.3.weight`, SiT의 `blocks.11.mlp.fc2.weight`, StyleSwin의 `layers.6.blocks.1.mlp.fc2.weight`다. TATOOED는 여러 층의 가중치를 고정 순서로 펼쳐 위치를 복원추출한다. 분류기 참조 목록은 최종 100개 출력층을 제외한 MobileNet 109개 및 ResNet18 40개 텐서다. 생성기에서는 최종 출력층을 제외한 내부 합성곱·선형 가중치를 사용한다. SiT에서는 이 대상에 LessMark가 쓰는 내부 `blocks.11.mlp.fc2.weight`도 포함된다. 중복 위치는 구현의 마지막 쓰기를 따른다. γ와 분산 길이 R은 독립 파라미터다. 원문은 약 20만 개의 분산 위치를 사용했다. 이번 비교는 등록된 대상 가중치의 전체 좌표 수 N에서 R=⌊N/800⌋(비율 0.00125)개 위치를 복원추출하는 참조 구현을 따른다. R은 MobileNet **13,251**, ResNet18 **13,964**, 두 U-Net 각각 **690,594**, 두 SiT 각각 **161,725**, StyleSwin **60,989**다. 복원추출로 중복이 생길 수 있으므로 서로 다른 위치 수는 저장된 위치 배열의 고유값 수로 구한다. 한 조건의 다섯 후보는 같은 위치 배열·키를 공유하고 γ만 바꾼다. 분류 가중치 설정[^archive-2] · [네 방법의 손실·복호](../runtime/comparison/protocol_v2/methods.py) · [생성 모델별 대상 층](../runtime/comparison/protocol_v2/generative_comparators.py) · [TATOOED 분산·복호](../runtime/comparison/protocol_v2/tattooed.py)

### LessMark를 삽입하는 층

아래 다섯 모델에서 공통 메시지 256비트를 표의 가중치(`weight`)에 직접 삽입한다. 두 분류기는 과제별 클래스 점수를 만드는 분류 헤드 앞의 백본 합성곱을 쓴다. 이 위치에서는 헤드 전체를 교체해도 삽입층과 그 가중치에서 비트를 읽을 수 있다. 백본까지 미세조정해 생기는 변화는 FT 후 BER로 측정한다. U-Net과 SiT-B/2는 ImageNet과 Caltech256에서 각각 같은 층을 사용하며, 삽입 방향은 각 도메인의 추가 학습을 마친 미삽입 모델 `C_T`와 해당 도메인의 훈련 사진으로 따로 계산한다.

### LessMark의 모델별 기저와 원본 기준점

원래 도메인 과제만 T만큼 추가 학습한 `C_T`에서 대상 가중치를 행렬 `W_ref`로 펼치고 해당 층의 입력 특징 hᵢ를 모은다. 평균을 빼지 않은 2차 모멘트 `M=(1/N)Σ sᵢhᵢhᵢᵀ`를 FP64로 누적·대칭화한다. 고유값이 작은 순서의 고유벡터 256개를 열로 모아 E를 만든다. 각 열의 최대 절댓값 성분 부호는 양수로 맞춘다. SiT에서는 내부 층의 변화가 최종 속도 출력에 미치는 국소 민감도로 가중하며, 다른 모델의 sᵢ는 1이다. 분류에서는 삽입 합성곱이 실제로 받는 패치로 그 합성곱 출력 변화가 작은 방향을 구한다. 최종 클래스 점수에는 이후의 정규화와 비선형 연산 등이 작용하므로, 최종 top-1 정확도는 모든 후보에서 별도로 측정한다.

**분류 백본에서 줄이는 변화량.** 같은 사진을 삽입 직전·직후 모델에 넣으면, 삽입층 앞까지의 가중치가 같아 합성곱 입력 패치 h도 같다. 비교하는 값은 패치 h에 대한 **배치 정규화(BN) 직전 합성곱 출력의 차이** Δy=ΔW h다. 단위 출력 방향 q와 ±1 메시지 b를 쓰면 ΔW=α q(Eb)ᵀ이며, 256비트에서 가중치 변화의 프로베니우스 노름은 16α다. 같은 α에서 기저를 바꿔도 삽입량은 같다. FP32 반올림 전, 기저를 계산한 N개 패치에서 위치당 제곱 변화의 평균은 `(1/N)Σ‖ΔW hᵢ‖² = α² bᵀEᵀMEb = α² Σⱼ λⱼ`다. 마지막 합은 선택한 256개 고유값의 합이다. 같은 입력 모멘트에서 고유벡터 256개를 고를 때, 가장 작은 고유값 256개에 대응하는 방향을 골라야 이 합이 최소가 된다. 출력 채널까지 평균한 MSE는 이 값을 출력 채널 수로 나눈다. 이 등식은 표본의 합성곱 출력에 대해 성립한다. 미사용 사진의 최종 분류 점수, top-1 정확도와 전층 미세조정 후 BER는 측정값으로 보고한다. | 모델 | 방향 계산에 쓰는 특징과 표본 | 출력 방향 q |
| --- | --- | --- |
| MobileNetV3-Large | 클래스 비례 훈련 사진 16,384장. 1×1 합성곱의 각 출력 위치에 들어오는 1,536차원 입력 벡터. 표본 시드 3199773557 | 출력 채널 256개, 시드 1022235315 |
| ResNet18 | 클래스 비례 훈련 사진 16,384장. 3×3 합성곱의 각 출력 위치에 들어오는 512 × 3 × 3 입력 패치를 펼친 4,608차원 벡터. 표본 시드 2458005299 | 출력 채널 512개, 시드 3855340113 |
| U-Net | 마지막 합성곱 입력의 256채널 3×3 패치. 도메인별 실사진 1,000장 × 잡음·시간 4회 × 64위치 = 256,000패치 | (1,1,1)/√3 |

**분류 합성곱의 패치 수집.** 모델별로 정제한 CIFAR-100 훈련셋에서 뽑은 16,384장을 평가 전처리(짧은 변 256픽셀, 중앙 224×224 자르기)로 읽고, 고정한 `C_T`를 평가 모드로 실행한다. 두 삽입층 모두 출력 특징맵이 7×7이므로 사진마다 49개 위치를 전부 사용한다. 따라서 각 모델은 **16,384 × 49 = 802,816개 패치**로 2차 모멘트를 계산한다. 입력 패치는 실제 합성곱의 스트라이드와 패딩을 적용한 뒤 가중치와 같은 채널·커널 순서로 펼친다. ResNet18의 경계 위치에는 원래의 0 패딩을 포함한다.

**U-Net과 SiT에서 사진 한 장을 사용하는 방법.** 두 모델 모두 같은 사진에 잡음과 시간을 새로 뽑아 네 가지 입력을 만든다. U-Net은 사진 픽셀에 해당 확산 시점의 잡음을 섞고 매번 64개 위치에서 패치 특징을 읽는다. SiT는 사진과 클래스는 고정하고, 매회 고정 VAE의 사후분포에서 잠재값 z, 표준정규 잡음 ε, 균등분포에서 연속 시간 t(0 ≤ t < 1)를 새로 뽑는다. 보간값 (1−t)ε+tz와 t, 클래스를 입력한 뒤 64개 토큰 위치의 특징을 읽는다. 두 모델 모두 사진당 256개, 모델·도메인당 256,000개 특징을 얻는다. [SiT·U-Net 입력 생성](../runtime/comparison/protocol_v2/generative_embed.py#L52) · [SiT 내부 특징 수집](../experiments/sit_internal_readout_20261110/internal_carrier.py#L138)

사진 번호 j와 반복 번호 r을 0부터 세면 전체 시행 번호는 i=4j+r이다. U-Net과 SiT는 각 모델·도메인에서 그 4,000회 순전파로 계산한 기저 하나를 다섯 LessMark 강도에 공유한다. 두 SiT 조건 모두 같은 다섯 α를 적용하고 각 조건의 종료 시점 BER로 강도를 선정한다. [실험 설정](config/NEXT_EXPERIMENT_DESIGN.json)

**StyleSwin에서 사진 한 장을 사용하는 방법.** 고정 목록의 첫 FFHQ 사진(순번 0, ID 59737)을 예로 든다. 난수 생성기에 시드 100을 주고 사진 픽셀과 독립적으로 표준정규 난수 512개를 생성한다. FFHQ에서 2,048회 추가 학습한 미삽입 생성기 `C_T`의 가중치를 고정하고 이 초기 벡터로 얼굴을 만든다. 그 얼굴과 256×256으로 줄인 FFHQ 사진의 픽셀 오차를 계산하고, 오차를 줄이는 방향으로 **벡터의 숫자만** 조정한다. 찾은 벡터로 고정한 `C_T`를 한 번 실행해 최종 이미지의 64개 위치에 대응하는 일곱 ToRGB 분기의 특징을 모은다. 따라서 특징은 각 실사진을 재구성하는 생성기 경로에서 나온다. StyleSwin에는 확산 시간 입력이 없다. [StyleSwin 공식 생성기](https://github.com/microsoft/StyleSwin/blob/main/models/generator.py#L597-L642) · [사진별 특징 수집 코드](code/styleswin_photo_features.py)

사진당 200회는 모든 얼굴에 같은 재구성 계산량을 배정하려고 본 실험에서 정한 업데이트 예산이다. 이 예산 안에서 각 사진의 픽셀 MSE로 특징 수집에 사용할 벡터를 고른다. 정렬된 FFHQ PNG를 Lanczos로 256×256으로 줄여 [0,1] RGB로 읽는다. 모델을 평가 모드로 고정하고, 표준정규분포에서 뽑은 초기 벡터 `z₀`를 Adam으로 200회 갱신한다(학습률 0.05, β₁=0.9, β₂=0.999). 손실은 생성기의 출력 정규화를 역변환한 RGB 값과 실사진 사이의 픽셀 MSE다. 최적화 중에는 출력값을 자르지 않는다. 초기 벡터 `z₀`의 MSE는 갱신 전 기준값으로 기록한다. 특징 수집에는 갱신된 200개 벡터(`z₁`부터 `z₂₀₀`까지) 중 MSE가 가장 작은 벡터를 사용한다. 모든 사진을 수집에 포함하고, 각 사진의 선정 벡터·선정된 갱신 번호(1~200)·초기 MSE·갱신 후 후보의 최소 MSE·선택 위치를 기록한다. 갱신 후 최소 MSE가 같은 경우 먼저 도달한 벡터를 보관한다. 잠재벡터를 찾는 동안 생성기 가중치는 고정되며 특징은 선택된 벡터에서 한 번만 수집한다. FFHQ 잠재벡터를 계산하는 프로세스는 시작 시 `CUBLAS_WORKSPACE_CONFIG=:4096:8`을 설정한다. PyTorch 결정적 연산을 활성화하고 cuDNN 벤치마크를 끈다. 실행에서 얻은 잠재벡터와 기저를 파일 및 SHA-256으로 고정해 다섯 LessMark 강도가 같은 기저를 사용하게 한다.

분류 q는 삽입 합성곱의 출력 채널 수만큼 가우시안 난수를 뽑아 평균을 빼고 단위 길이로 만든다. ImageNet U-Net의 입력·패치 표본은 Torch와 NumPy 각각 시드 100에서 난수열을 이어 쓴다. Caltech U-Net과 두 SiT에서는 0부터 센 시행 i의 입력 시드는 100+i, 위치 시드는 100100+i다. StyleSwin에서는 고정 목록의 사진 순번 j를 0부터 세고 초기 잠재벡터 시드 100+j, 위치 시드 100100+j를 사용한다. SiT의 관측 가중치는 `sᵢ=‖Jᵢ(gᵢ⊙q)‖²`이며 gᵢ는 MLP 출력 게이트, Jᵢ는 이어지는 정규화·출력층에서 속도 16성분에 이르는 국소 변화율이다. StyleSwin은 업샘플링으로 각 분기를 같은 픽셀 위치에 맞추고 채널 512·512·512·512·256·128·128개를 차례로 연결한다. 각 모델·도메인의 `C_T`에서 산출한 기저를 해당 조건의 다섯 강도에 공유한다.

```text
삽입       Wₘ = FP32(W_ref + α q (E b)ᵀ)
복호 점수  r  = Eᵀ (W★ − W_ref)ᵀ q
```

W★는 지금 읽을 워터마크 모델의 대상 가중치다. StyleSwin은 변화량을 본래 채널 경계에서 나누어 일곱 분기에 쓴다. 삽입 직후와 가지치기·양자화·FT 후 모두 **삽입 직전 `C_T`에서 고정한 기준 가중치 `W_ref`와 기저 E, 출력 방향 q**로 비트별 복호 점수 256개(r)를 계산한다. 점수가 양수인 자리는 1, 음수인 자리는 0이며 하나라도 정확히 0이면 전체 판정 불가다. 품질 비교에는 삽입 직후의 `C_T` 또는 해당 변형을 같은 수준으로 적용한 대조군을 사용한다. [기저 계산](../runtime/comparison/protocol_v2/carriers.py) · [생성 기저 입력](../runtime/comparison/protocol_v2/generative_embed.py) · [가중치 판독](../runtime/comparison/protocol_v2/methods.py)

### 원본을 불러온 뒤 수행할 삽입 학습

각 조건에서 C₀를 원래 도메인의 과제 손실로 T만큼 추가 학습해 미삽입 대조군 `C_T`를 한 번 만든다. 학습형 네 방법(VanillaMark·GreedyMark·NeuralMark·DeepMark)은 각 강도에서 같은 C₀를 독립적으로 복사하고 첫 업데이트부터 마지막까지 **원래 과제 손실 + λ × 워터마크 손실**로 학습한다. LessMark·TATOOED는 각 강도마다 같은 `C_T`를 복사해 신호를 더한 직후 판독한다(삽입 후 추가 업데이트 `t_embed=0`). 분류의 원래 과제는 CIFAR-100 정답 클래스의 교차엔트로피다. 생성의 원래 과제와 실제 학습 목표는 다음과 같다.

| 생성 모델 | 원래 도메인의 훈련 입력 | W와 C가 공통으로 학습하는 과제 |
| --- | --- | --- |
| U-Net · ImageNet 또는 Caltech256 | 실제 사진 x에 시간 단계별 가우시안 잡음 ε를 섞은 이미지와 시간 단계 | 실제로 넣은 ε와 예측한 잡음 사이의 MSE를 줄이고, 역확산 분산을 학습하는 가중 변분 손실을 더한다. |
| SiT-B/2 · ImageNet 또는 Caltech256 | 고정 VAE로 얻은 사진 잠재값 z, 잡음 ε, 시간 u, 원래 도메인의 클래스 | 보간값 (1−u)ε+uz에서의 예측 속도와 목표 속도 **z−ε** 사이의 MSE를 줄인다. 정답은 그 시행에 사용한 사진 잠재값과 잡음에서 계산한다. |
| StyleSwin-256 · FFHQ | 생성기는 512차원 표준정규 잠재벡터로 얼굴을 만든다. 각 비교군의 판별기는 FFHQ 실사진과 자기 생성기가 만든 얼굴을 입력받는다. | 생성기는 자기 판별기가 생성 얼굴을 실제로 판단하도록 **비포화 로지스틱 손실**을 줄인다. 판별기는 **실제·생성 분류의 로지스틱 손실 + R₁ + bCR**로 학습한다. 워터마크 항은 W의 생성기에만 더한다. |

원래 도메인 학습과 새 도메인 FT에서 기본 생성 과제의 학습 신호는 **실제 훈련 이미지와 위 과제의 목표**에서 얻는다. 같은 입력에서 C와 W가 각각 만든 RGB 이미지의 MSE·SSIM은 각 후보의 검증 품질과 선정 후 테스트 품질을 나타낸다. 강도 순위는 가중치에서 읽은 종료 시점 BER로 계산한다. **원 논문과의 대조.** ADM은 잡음 예측 MSE와 역확산 분산에 대한 가중 변분 손실을 함께 쓴다. SiT 원문은 여러 보간 경로·목적함수를 비교했고, SiT-B에서 선형 경로와 속도 MSE 조합을 평가했다. 원문의 시간 표기는 데이터에서 잡음 방향이다. 저자 코드와 위 표는 잡음에서 데이터 방향이므로 목표 속도는 z−ε다. [ADM §2](https://proceedings.neurips.cc/paper_files/paper/2021/file/49ad23d1ec9fa4bd8d77d02681df5cfa-Paper.pdf#page=3) · [Improved DDPM 식 (15)](https://proceedings.mlr.press/v139/nichol21a/nichol21a.pdf#page=4) · [SiT 식 (7)·(12), 그림 5](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/09828.pdf) · [SiT 저자 코드의 시간 방향](https://github.com/willisma/SiT/blob/cbde832a40b153ccc79603412409da9c9b0c568c/transport/path.py#L18-L29)

**StyleSwin 정규화.** R₁은 실제 이미지에 대한 판별기 점수의 입력 기울기를 제한한다. FFHQ-256 원 설정처럼 γ=10으로 두고 통상 판별기 학습 16회마다 별도 갱신한다(0부터 센 반복 번호 0, 16, 32, …). 이때 이미지별 입력 기울기의 제곱합을 배치에서 평균 낸 값에 `(γ/2)×16`을 곱한다. bCR은 실제·생성 이미지 각각에서 증강 전후 판별기 점수의 제곱 차이를 줄이며, 가중치는 각각 10이다. FFHQ 삽입에는 원문의 두 정규화 규칙을 적용한다. **ArtBench FT에서도 이 계수와 주기를 유지하는 것은 이번 연구의 결정**이다. [StyleSwin §4.2](https://openaccess.thecvf.com/content/CVPR2022/papers/Zhang_StyleSwin_Transformer-Based_GAN_for_High-Resolution_Image_Generation_CVPR_2022_paper.pdf) · [보충자료 §1·표 1](https://openaccess.thecvf.com/content/CVPR2022/supplemental/Zhang_StyleSwin_Transformer-Based_GAN_CVPR_2022_supplemental.pdf#page=1)

**같은 학습량의 clean 대조군.** W와 C는 매 업데이트에 같은 실사진·배치 순서, 증강·잡음·시간·조건 난수, 갱신 대상, 옵티마이저 초기 상태와 학습률 일정을 쓰되 각자의 가중치와 옵티마이저 상태를 갱신한다. 같은 모델·데이터셋 조건의 네 학습형 방법과 다섯 강도에 같은 과제 학습 설정과 T를 적용한다. 종료 대조군 체크포인트의 해시를 기록해 모든 비교와 직접 삽입에 같은 파일을 사용한다. StyleSwin의 C₀는 생성기 `g_ema` 가중치다. FFHQ 삽입 학습을 시작할 때 동일하게 초기화한 판별기를 각 비교군에 별도로 복사하고 생성기·판별기의 갱신 비율과 순서를 맞춘다. StyleSwin의 학습량은 **생성기 옵티마이저의 누적 업데이트 수**로 세고 판별기 업데이트 수는 따로 기록한다. 공개 EMA는 시작 가중치로 쓰며, 이후 BER·RGB 평가와 세 가지 강건성 평가에는 실제로 갱신한 생성기 가중치를 사용한다.

StyleSwin은 저자 코드의 주기적 정규화 보정을 따른다. 주기 k에 대해 기본 학습률에 k/(k+1)를 곱하고 Adam의 β를 같은 지수로 거듭제곱한다. D의 k=16, G의 k=10,000,000이다. 통상 D 업데이트의 기울기 노름 상한은 5다. 조건별 배치 순서·증강·잡음·시간·클래스 입력은 절대 업데이트 번호와 고정 시드에서 재현한다. 분류 설정은 두 원본의 등록 학습 설정을 따랐고, 생성 설정의 수치와 메모리에 맞춘 마이크로배치는 이 비교를 위한 공통 조건이다. 평가에는 FP32 종료 가중치를 사용한다.

GreedyMark와 NeuralMark는 공통 목표 메시지 사용과 기학습 원본에서 삽입 시작을 모두 명시한다. NeuralMark에서 비밀 키의 해시는 필터를 만드는 데 쓰이며, 여기서 확인하는 값은 공통 타깃의 복원 상태와 BER다. 원 논문의 소유권 검증 조건인 H(키)=메시지는 이 변형의 판정에 쓰지 않는다.

### StyleSwin-256의 잠재벡터, 학습 순서와 누적 입력 수

StyleSwin에서 잠재벡터 **z**는 생성기에 넣어 이미지 한 장을 만드는 512개의 실수다. 저자 학습 코드는 `torch.randn((args.batch, 512))`를 호출해 각 성분을 **평균 0, 표준편차 1인 정규분포에서 독립적으로** 뽑는다. 사진에 노이즈를 더하거나 확산 시간 단계를 지정하는 과정은 없다. [저자 코드의 잠재벡터 추출](https://github.com/microsoft/StyleSwin/blob/a7c28b3121ca86f0577696d6f1d699e13d368672/train_styleswin.py#L131-L197)

| 용도 | 잠재벡터를 어떻게 정하는가 | 무엇을 갱신·측정하는가 |
| --- | --- | --- |
| **학습형 삽입 · ArtBench FT** | 매 반복마다 판별기용 벡터와 생성기용 벡터를 실사진과 독립적으로 새로 뽑는다. 같은 단계의 W와 C에는 **동일한 벡터**를 넣는다. | 각 모델이 자기 판별기와 GAN 과제를 학습한다. 삽입할 때만 W의 생성기에 워터마크 항을 더한다. |
| **LessMark 방향 계산** | 사진 순번으로 시드를 정해 픽셀과 독립적으로 표준정규 초기 z를 생성한다. 이후 FFHQ 훈련 사진 1,000장을 각각 재구성 목표로 삼아 **z만** 최적화한다. | 2,048회 추가 학습한 미삽입 생성기 `C_T`를 고정한다. 사진별로 갱신한 200개 벡터 중 최저 오차의 벡터에서 ToRGB 특징을 수집해 다섯 강도가 한 기저를 공유한다. |
| **삽입 검증 · 삽입 직후와 각 변형 후 테스트** | 검증·테스트용 시드로 표준정규 벡터를 각각 1,000개 고정한다. 두 목록은 서로 겹치지 않고 학습용 난수와 분리한다. 삽입 직후와 가지치기·양자화·FT 후 테스트에는 같은 테스트 목록을 쓴다. | 각 벡터를 두 생성기에 똑같이 넣어 최종 RGB 출력의 MSE·SSIM을 비교한다. 워터마크 모델의 가중치에서 읽은 256비트로 BER를 계산한다. |

저자의 FFHQ-256 공개 명령은 모델을 처음부터 **전체 배치 32**(GPU 8개 × 4장), 100만 반복으로 학습한다. 배치는 한꺼번에 처리하는 입력의 묶음이고, 업데이트는 손실을 이용해 한 모델의 가중치를 조정하는 한 번의 연산이다. 이번 FFHQ 삽입 학습은 유효 배치 32에서 **통상 판별기 1회 → 해당 반복이면 R₁ 판별기 1회 → 생성기 1회**를 한 반복으로 적용한다. 생성기 2,048회에 통상 판별기 2,048회와 추가 R₁ 판별기 128회가 대응한다. [저자 FFHQ-256 학습 명령](https://github.com/microsoft/StyleSwin/blob/a7c28b3121ca86f0577696d6f1d699e13d368672/README.md#L90-L95)

| 한 번의 반복 | 손실에 쓰는 입력과 갱신 대상 |
| --- | --- |
| ① 판별기 갱신 | FFHQ 훈련 얼굴 32장을 꺼낸다. 실사진과 독립적으로 512차원 잠재벡터 32개를 뽑아 현재 생성기로 합성 얼굴 32장을 만든다. 생성기를 고정하고, 두 종류의 얼굴을 구분하도록 판별기를 갱신한다. bCR은 같은 이미지의 증강본을 쓰고, R₁을 적용하는 반복에도 같은 실사진을 재사용한다. |
| ② 생성기 갱신 | 판별기를 고정하고 **새 잠재벡터 32개**로 얼굴을 만든다. 판별기가 이 얼굴을 실제로 평가하도록 생성기를 갱신한다. FFHQ 삽입 때에는 W의 생성기에만 워터마크 손실을 더한다. 이 단계가 끝나면 생성기 업데이트가 1회 증가한다. |

GAN 학습에서 FFHQ 사진은 판별기에 보여 주는 실제 얼굴 예시다. 각 잠재벡터에 정답 얼굴을 지정할 필요가 없다. 아래는 **C_T 또는 학습형 후보 한 개를 학습할 때 손실에 들어가는 누적 입력 수**다. R₁의 추가 판별기 갱신은 같은 실사진을 재사용하므로 추가 입력으로 세지 않는다. 저자 코드가 생성기 단계에서 추가로 읽는 실사진 배치는 생성기 손실에 쓰이지 않아 집계에서 제외한다. [저자 코드의 두 갱신 단계](https://github.com/microsoft/StyleSwin/blob/a7c28b3121ca86f0577696d6f1d699e13d368672/train_styleswin.py#L131-L197)

| 생성기 누적 업데이트 | 판별기 손실에 사용한 실사진(반복 포함) | 추출한 512차원 잠재벡터(두 단계 합계) |
| ---: | ---: | ---: |
| 256 | 8,192장분 | 16,384개 |
| 512 | 16,384장분 | 32,768개 |
| 1,024 | 32,768장분 | 65,536개 |
| 2,048 | 65,536장분 | 131,072개 |

**FFHQ 훈련 사진의 재사용.** 판별기 손실에 60,000장을 한 번씩 사용하면 1에포크, 즉 1,875회 반복이다. 같은 훈련 목록을 다시 섞어 173회 동안 5,536장을 한 번 더 사용하면 생성기 업데이트가 2,048회에 이른다. 실사진을 재사용하는 반복에서도 두 단계의 잠재벡터 배치는 새로 뽑는다. FFHQ 검증 사진 10,000장은 보류한다. 등록된 ID 순서와 순회별 시드에서 실제 사용 목록을 재현한다. 모든 학습형 후보와 미삽입 생성기를 2,048회까지 학습하며, 이 종료 시점에서만 후보를 비교한다.

## 5. 고정 학습량에서의 삽입 강도 선정

### 대표 삽입강도와 42개 조합의 후보

**대표 삽입강도**는 다섯 후보를 계산할 때의 1배 기준값이다. 별도의 대표강도 탐색 실험 없이 아래 기준값을 사용한다. **최종 선정 강도**는 그 다섯 후보를 고정 학습량에서 측정한 뒤 조합별로 한 개씩 고른 값이다. 학습형 방법의 λ는 손실에 곱하는 계수이고, 직접 삽입의 α·γ는 가중치에 더하는 신호의 계수다. 강도의 수치와 동률 우선순위는 같은 방법·모델·데이터셋 안에서 비교한다.

비교 방법 35개 조합은 각 원 논문의 삽입 강도를 일곱 모델·데이터셋에 공통 적용한다. 해당 강도를 원 논문에서 평가하지 않은 아키텍처·도메인에도 쓰는 것은 이번 비교의 설계다. LessMark 7개 조합은 두 분류기에 α=0.2, 두 U-Net에 α=0.1, 두 SiT와 StyleSwin에 α=1을 이번 실험의 기준값으로 지정한다. 모든 기준값에 **¼, ½, 1, 2, 4배**를 적용해 다섯 후보를 미리 고정한다. 생성 손실이 바뀐 20개 조합도 이 규칙으로 확정한 다섯 강도를 그대로 평가한다. ### 종료 시점에서 강도 하나를 고르는 방법

1. 조합의 다섯 종료 가중치 각각에서 ID 292의 정보를 한 번 복호한다. 정상 상태로 반환된 256비트에는 오류 개수와 BER를 기록한다. 판정 불가·비수렴·비정상 반환은 상태와 사유를 기록하고 순위에서 제외한다.
2. **정상 복호 후보 중 종료 BER가 가장 낮은 후보**를 고른다. 최소 BER가 같은 후보가 여럿이면 **그중 가장 큰 강도**를 고른다. 예를 들어 다섯 강도의 오류가 12·4·1·1·3비트이면 네 번째 강도를 선택해 BER=1/256로 보고한다. BER=0인 후보가 여러 개일 때도 같은 동률 규칙을 쓴다. 정상 복호 후보의 분모는 모두 256이므로 실제 오류 비트 수로 동률을 판정한다.
3. **모든 후보에서** 종료 가중치와 공통 `C_T`의 검증 품질을 측정한다. 분류는 5,000장으로 두 정확도와 하락 폭을, 생성은 같은 입력으로 만든 RGB 1,000쌍의 평균 MSE·SSIM을 기록한다. 양의 BER와 복호 실패를 포함해 다섯 후보의 품질을 모두 보고하며, 품질은 순위·동률·후속 평가 자격에 사용하지 않는다. 전체 검증 후 비유한 값(NaN·무한대)이 나온 분류 사진이나 생성 RGB 쌍이 있으면 해당 건수를 남기고 계산할 수 없는 품질값을 `undefined`로 표시한다. 이 경우에도 유효한 256비트는 같은 BER 규칙으로 순위를 매긴다.
4. 선정된 `W_T`와 대응 `C_T`를 원래 도메인에서 테스트하고, 그 쌍의 복사본으로 가지치기·양자화·다른 도메인 FT를 각각 수행한다. 변형 후 BER나 품질을 확인한 뒤 강도를 다시 고르는 절차는 없다. 다섯 후보 모두 정상 복호에 실패하면 조합을 **정상 복호 실패·미선정**으로 보고한다. 이 경우에도 다섯 종료점의 상태와 품질을 제시하고 선정 모델이 필요한 테스트·강건성 평가 칸에 사유를 남긴다.

## 6. 선정 모델의 강건성 평가

각 조합에서 선정한 `W_T`와 대응 `C_T`의 삽입 직후 테스트를 먼저 기록한다. **가지치기 30%, 가지치기 70%, 8비트 양자화, 4비트 양자화, 새 도메인 FT**는 모두 이 쌍의 새 복사본에서 독립적으로 시작한다. 선정 BER가 0보다 큰 조합도 다섯 평가에 포함한다. 각 평가에서 W의 복호 상태와 BER를 읽고, 같은 변형을 거친 C와 W의 품질을 비교한다.

### 가지치기와 가중치 양자화

| 변형 | 동일 조건으로 W·C 각각에 적용하는 연산 | 측정 |
| --- | --- | --- |
| 전역 절댓값 가지치기 30%, 70% | 지정한 텐서·행의 가중치를 고정 순서로 펼친다. 대상 원소 수 N과 제거 비율 p에 대해 절댓값이 작은 순서로 ⌊pN⌋개를 0으로 만든다. 같은 절댓값은 펼친 인덱스가 작은 순서로 처리한다. 마스크는 각 모델의 가중치에서 독립적으로 계산한다. | 각 비율을 한 번 적용한 직후, 추가 가중치 학습 없이 평가 |
| 대칭 가중치 양자화·역양자화(QDQ) 8비트, 4비트 | 텐서별 대상 가중치의 최대 절댓값을 8비트에서는 127, 4비트에서는 7로 나눠 스케일을 구한다. 각 가중치를 스케일로 나눠 가장 가까운 정수로 반올림하고(중간값은 짝수) 각각 [−127, 127] 또는 [−7, 7]로 제한한다. 여기에 스케일을 곱해 원래 부동소수점 자료형으로 되돌린다. 모두 0인 텐서는 0으로 둔다. 스케일은 각 모델의 가중치에서 독립적으로 계산한다. | 각 비트 폭을 한 번 적용한 직후, 추가 가중치 학습 없이 평가 |

두 변형은 실험 1의 물리적 가중치 목록과 행 범위를 이어 쓴다. 분류에서는 각 모델의 LessMark 삽입 합성곱과 최종 분류층을 포함한 MobileNet의 합성곱·선형 가중치 64개, ResNet18의 21개가 대상이다. 생성에서는 U-Net 182개, SiT-B/2 65개, StyleSwin 105개 가중치 텐서에 적용한다. U-Net의 최종층은 잡음 예측 행 0–2, SiT의 최종층은 속도 예측 행 0–3·8–11·16–19·24–27, StyleSwin의 일곱 ToRGB는 각각 RGB 세 행을 포함한다. 같은 조건의 여섯 방법은 동일한 텐서·행 목록을 쓰고, 실행마다 목록·수준·체크포인트 식별자를 기록한다. 실험 1의 변형 규약[^archive-11] · [MobileNet 대상 목록](../experiment_1/records/runs/test-evaluation-20261028-repair1/jobs/mobilenet_v3_large_w1p6_cifar100/main_config.lock.json) · [ResNet18 대상 목록](../experiment_1/records/runs/test-evaluation-20261028-repair1/jobs/resnet18_cifar100/main_config.lock.json) · 생성 모델의 대상 범위[^archive-12] · [분류 연산](../runtime/comparison/protocol_v2/modifications.py) · 생성 연산[^archive-13]

### 새 도메인 미세조정(FT)

같은 `W_T`와 `C_T`에서 출발해 두 모델을 각각 새 도메인의 실제 훈련 이미지로 학습한다. **두 모델 모두 워터마크 손실을 끈다.**

| 모델 | 새 도메인에서 수행하는 구체적인 학습 |
| --- | --- |
| 두 분류기 | FGVC-Aircraft의 100개 기종을 예측하는 교차엔트로피로 학습한다. 기존 출력층 100행을 유지하고 `variants.txt`의 기종 순서를 행 0~99에 대응시킨다. 출력층과 LessMark가 삽입된 백본 합성곱을 포함한 **전층**을 갱신한다. 이 FT의 BER는 백본 가중치가 실제 항공기 학습을 거친 뒤에 측정한다. |
| 두 U-Net | ArtBench 실제 회화에 시간 단계별 잡음을 더한다. 화풍 레이블 없이 실제 잡음을 예측하는 MSE와 역확산 분산의 가중 변분 손실로 학습한다. |
| 두 SiT-B/2 | 고정 VAE로 인코딩한 ArtBench 회화의 잠재값 z와 잡음 ε를 선형 보간하고, 예측 속도와 목표 z−ε 사이의 MSE를 줄인다. 화풍 10개의 조건 임베딩을 모든 비교군에서 동일하게 초기화하고 무조건 임베딩은 원본에서 이어받는다. |
| StyleSwin-256 | 선정된 각 생성기는 잠재벡터로 회화를 만들고 비포화 로지스틱 손실로 학습한다. ArtBench용 판별기는 모든 비교군에 같은 새 초기 상태를 복사한 뒤, 각자 실제 작품과 자기 생성기의 출력을 사용해 로지스틱 손실·R₁·bCR로 학습한다. 화풍 레이블은 쓰지 않는다. |

StyleSwin FT에 [4절의 기본 판별기 1회 → 생성기 1회 순서](#styleswin-training)를 적용하면, 전체 배치 B와 생성기 업데이트 수 T_FT에 대해 **모델당 실제 작품 B × T_FT장분, 잠재벡터 2 × B × T_FT개**를 쓴다. 판별기에는 ArtBench 훈련 작품 45,000장에서 구성한 미니배치를 제공한다. 정규화 계수와 주기는 FFHQ 때와 같고, 워터마크 항은 양쪽 모두 끈다.

**생성 FT 학습량.** 아키텍처·원래 도메인 조건마다 공통 FT 업데이트 수 T_FT를 본 FT 전에 정한다. 학습량의 예비 선정이 필요하면 clean 모델과 목표 도메인의 훈련·검증 분할만 사용한다. 본 FT에서는 여섯 방법과 대응 clean 대조군이 같은 사진·순서, 증강·잡음·조건 난수, 새 모듈 초기값, 갱신 대상, 옵티마이저와 학습률 일정을 사용해 각각 T_FT까지 학습한다. 원래 도메인의 고정 추가 학습량 T와 새 도메인의 FT 학습량 T_FT를 각각 기록한다.

**FT 중 검증.** 가중치를 고정한 채 ArtBench 검증 작품 5,000장과 고정한 검증 난수로 U-Net·SiT의 과제 손실을 점검한다. StyleSwin은 이 작품과 고정 잠재벡터에서 생성한 이미지로 각 비교군의 생성기·판별기 손실을 기록한다. 분류는 FGVC-Aircraft 검증 3,333장의 기종 예측 성능을 점검한다. 본 FT의 생성 모델은 모두 예정된 T_FT에서 저장한다. 이 쌍에서 7절의 테스트 노이즈로 최종 RGB 출력 차이를 측정하고 W-FT의 가중치에서 메시지를 읽는다. ## 7. 평가 입력·지표·집계

### 같은 입력을 두 번 쓰는 생성 비교

검증용 시드 범위는 **2,769,800,000~2,769,800,999**, 테스트용은 **3,769,800,000~3,769,800,999**이며 양 끝을 포함한다. `quality_sampling_seeds(stage, 7698, 1000)`의 stage는 검증에서 `development`, 테스트에서 `main`이며 두 목록은 겹치지 않는다. 범위를 정할 때 예비 검증 네 캠페인과 확인된 삽입 직후 테스트 사례의 RGB 시드와도 겹침이 없음을 확인했다. 같은 조건의 모든 방법·강도에는 같은 검증 목록과 샘플러를, 선정 후에는 같은 테스트 목록과 샘플러를 적용한다. **한 입력에서 C와 W가 각 한 장씩** 생성하므로 1,000입력은 **1,000쌍**이다. 시드 정의[^archive-1] · [평가 설정](config/NEXT_EXPERIMENT_DESIGN.json)

| 모델 | 한 쌍에 고정하는 입력과 RGB 생성 절차 |
| --- | --- |
| U-Net | 같은 시작 가우시안 RGB 잡음. 모델 정의의 선형 1,000단계 확산을 250단계로 재배치하는 DDIM, η=0, denoised clipping을 쓰는 참조 샘플러에서 최종 출력을 [0,1]로 변환 |
| SiT-B/2 | 같은 잠재 잡음과 같은 조건. 삽입 직후와 가지치기·양자화 후에는 해당 ImageNet/Caltech 클래스, FT 후에는 같은 ArtBench 화풍. 참조 샘플러는 선형 경로 속도 ODE, dopri5 적분점 250, CFG 4.0, atol 10⁻⁶, rtol 10⁻³. 최종 잠재값을 고정 VAE로 복호 |

### 보고할 값과 방향

| 측정 | 삽입 직후 | 가지치기·양자화 후 (각 수준) | 다른 도메인 FT 후 |
| --- | --- | --- | --- |
| 분류 top-1 | CIFAR-100 테스트 10,000장의 두 정확도와 하락 폭 **정확도(`C_T`)−정확도(`W_T`)**(%p) | 같은 CIFAR-100 10,000장에서 변형된 C와 W의 두 정확도 및 **C−W**(%p) | 항공기 테스트 3,333장의 두 정확도 및 **W-FT−clean-FT**(%p). 음수이면 W-FT가 낮음 |
| 생성 출력 | 같은 테스트 입력에서 `C_T`와 `W_T`의 RGB 1,000쌍 평균 MSE·SSIM | 같은 테스트 입력에서 같은 수준으로 변형한 C와 W의 RGB 1,000쌍 평균 MSE·SSIM | 같은 테스트 시드에서 clean-FT와 W-FT의 RGB 1,000쌍 평균 MSE·SSIM |
| 메시지 | `W_T`의 가중치를 읽어 ID 292의 256비트와 대조 | 변형된 W의 가중치에서 동일한 메시지를 읽어 오류 수·BER·상태를 삽입 직후와 나란히 보고 | W-FT의 가중치에서 동일한 메시지를 읽어 오류 수·BER·상태를 삽입 직후와 나란히 보고 |

MSE는 한 쌍에서 같은 RGB 채널·픽셀끼리의 차이를 제곱해 모두 평균한다. SSIM은 [0,1] 범위, 11×11 가우시안 창(σ=1.5), K₁=0.01, K₂=0.03, 모집단 공분산, 패딩 없는 유효 합성곱과 FP64 연산을 사용한다. 위치·채널 평균을 쌍별로 낸 뒤, MSE·SSIM 각각을 1,000쌍에서 산술평균한다. MSE가 낮고 SSIM이 높을수록 동일 입력에서 두 모델의 출력이 가깝다. 회화 생성기의 절대적 품질이나 실제 화풍 분포와의 거리는 본 지표의 측정 대상에서 제외된다. [RGB 지표 구현](../runtime/comparison/protocol_v2/generative_quality.py)

정상 복호 시 `BER=불일치 비트 수/256`이며 퍼센트는 100을 곱한다. 1비트 오류는 0.390625%다. 반환 비트열이 없거나 비정상이면 상태를 별도로 기록한다. 예컨대 TATOOED가 비수렴 상태에서 256개의 이진 추정값을 반환하면 상태·반환 길이·진단용 오류 수를 따로 기록한다. 이 후보의 선정용 오류 수와 BER 칸은 비워 둔다. 정상 완전 복원 판정은 복호 상태가 정상이며 오류가 0일 때에만 성립한다. 한 체크포인트에서 한 번 읽은 가중치 BER는 테스트 사진이나 생성 입력 개수로 나누지 않는다. 같은 방법·모델·수준마다 삽입 직후 값과 변형 후 값을 함께 두어 처음부터 남아 있던 오류와 변형 후의 총오류를 구분한다. 변형 후 판독 실패도 해당 수준의 결과에 남긴다.

### 왜 1,000쌍인가

실험 1의 64쌍 검증에서 Caltech U-Net–LessMark의 α=0.24는 평균 SSIM 0.96611, 해당 쌍을 단위로 복원추출한 평균의 95% 구간은 [0.95516, 0.97580]으로 당시 품질 기준 0.97을 가로질렀다. α=0.12는 0.98473 [0.97679, 0.99117]이었다. 백분위 부트스트랩 20,000회, PCG64 시드 20261122를 썼다.

네 예비 캠페인의 후보·체크포인트별 검증 기록 219개(44+12+159+4) 각각에서 64쌍의 표본표준편차 s를 계산했다. X를 MSE 또는 1−SSIM, L을 각각 0.002 또는 0.03이라 하고 평균의 목표 오차폭을 `h=0.1×max(L, 평균 X)`로 정했다. 95% 정규근사 `ceil((1.96s/h)²)`를 각 기록에 적용한 최댓값이 MSE **919쌍**, SSIM 손실 **609쌍**이므로 1,000쌍으로 올렸다. 10%는 정한 정밀도 목표다. 같은 입력을 여러 후보에서 재사용한 기록이 있어 파일 단위로 계산했다. 네 입력 원천은 일반 강도 탐색 44건[^archive-14], LessMark 강도 탐색 12건[^archive-15], 비교 방법 159건[^archive-16], StyleSwin 확장 4건[^archive-17]에 있다. 각 후보의 `quality.json`에서 `matched_clean_vs_marked.records` 또는 직접 저장된 `records`의 쌍별 지표를 읽는다. 계산 근거는 원래 도메인의 고정 모델별 통계이며 도메인 전이 후의 달성 정밀도는 실제 FT 출력에 달려 있다. 최대 MSE 표본 수 근거[^archive-18] · 최대 SSIM 손실 표본 수 근거[^archive-19] · [표본 수 계획](config/NEXT_EXPERIMENT_DESIGN.json)

## 8. 실행 순서와 산출물

1. 일곱 C₀의 경로·크기·해시, 훈련·검증·테스트 목록, 수신자 비트 순서, 42개 조합의 다섯 강도, 고정 종료 시점, 평가 시드를 대조한다. 이 폴더의 `python3 -B code/verify_design.py`로 명세와 입력을 점검한다. [설계 검증기](code/verify_design.py) · [강도표](config/FIVE_STRENGTH_CANDIDATES_REVIEW.csv)
2. 조건별 C₀를 과제만으로 T만큼 학습하고 미삽입 종료 모델 `C_T`와 해시를 보관한다. 학습형은 각 강도에서 C₀부터 독립적으로 T까지 공동 학습한다. 직접 삽입형은 강도마다 같은 `C_T`의 복사본에 삽입한다. LessMark는 삽입 전에 `C_T`에서 방향과 기준 가중치를 고정하며 StyleSwin은 사진별 선정 벡터·초기 및 최소 오차·선택 위치도 저장한다.
3. 210개 후보 각각에서 강도, 실제 과제 업데이트 수, 삽입용 업데이트 수, 종료 가중치와 공통 대조군의 식별자, 복호 상태·오류 수·BER, 원래 도메인 검증 품질을 저장한다. 정상 복호 실패는 이유를 남긴다. 재개에 필요한 모델·옵티마이저·일정·난수·배치 위치와 StyleSwin 판별기 상태·갱신 횟수도 보관한다.
4. 조합마다 종료 BER와 동률 규칙으로 선정 강도를 결정하고 근거가 된 다섯 후보를 함께 보고한다. 선정한 `W_T`와 `C_T`를 원래 도메인 테스트에서 비교한 뒤, 6절의 가지치기 두 수준·양자화 두 수준·다른 도메인 FT에 각각 넘긴다. 42개 조합이 모두 선정되면 삽입 직후 42쌍과 변형 후 210개 조합·수준을 보고한다. 변형별 입력·출력 체크포인트 식별자와 적용 범위, 가지치기 마스크·양자화 스케일 또는 FT 학습 기록, 복호 상태·오류 수·BER와 대응 품질을 보관한다. 미선정 조합도 전체 42개 집계에 남긴다.
5. 강도 선정 실행기는 지정한 출력 경로에 다섯 후보의 종료 가중치와 측정표를 저장하고 선택된 파일을 참조한다. 각 조합의 삽입 직후 테스트와 변형 평가는 그 참조를 인계받는 후속 단계다. [강도 선정 실행기](code/run_strength_selection.py) · [결과 파일 안내](results/README.md)

**정밀도와 실행 환경.** 참조 구현은 FP32 가중치와 LessMark 기저·복호의 FP64 연산을 RTX 4090, PyTorch 2.5.1, CUDA 12.1에서 검증했다. 이번 실행의 실제 GPU, 소프트웨어 버전과 연산 정밀도는 실행별 설정·로그에 기록한다.

**실행과 재개.** 전체 실행에는 7개 조건별 대조군 학습 7회, 4개 학습형 방법의 후보 학습 140회, 2개 직접 삽입 방법의 가중치 조작 70회가 필요하다. 분류의 옵티마이저 갱신은 대조군을 포함해 2 × 21 × 140,400 = **5,896,800회**, 생성의 모델·생성기 갱신은 5 × 21 × 2,048 = **215,040회**다. 각 조건의 C_T, clean 검증 정확도 또는 clean RGB 1,000장, 방법별 키·LessMark 기저는 필요한 조건·방법에서 한 번만 준비한다. 병렬 워커에서는 두 U-Net과 두 SiT가 ImageNet·Caltech256 원본 사진의 SHA-256을 기준으로 256×256 중앙 자르기 결과를 공유한다. 같은 사진은 최초 사용 시 한 번만 디코딩해 8비트 RGB로 저장하고, 좌우 반전은 매번 원래의 추출 시드로 결정한다. 두 도메인의 훈련 목록 45,713건에서 SHA-256이 서로 다른 원본은 45,710개다. 모두 사용하면 캐시에 약 9.0 GB가 필요하다. 클래스와 데이터셋 배정은 각 도메인의 훈련 목록을 따른다. 두 SiT 조건은 고정 VAE에서 얻은 보간 잠재값, 시간, 목표 속도와 클래스 입력을 업데이트별로 저장해 해당 대조군과 학습형 20개 후보가 재사용한다. 각 SiT 모델의 예측과 역전파는 후보별로 계산한다. StyleSwin은 훈련 얼굴을 처음 읽을 때 양선형 보간으로 줄인 256×256 RGB를 정규화 전 8비트 정수로 저장한다. 대조군과 각 후보가 같은 사진을 다시 사용할 때 이 사본을 읽는다. 60,000장의 픽셀 자료는 약 11.8 GB이며 파일 정보는 별도다. LessMark의 사진별 잠재벡터 최적화는 고정 목록의 원본 PNG를 Lanczos 보간해 사용한다.

**대조군의 계산 단위.** 모델과 원래 도메인의 쌍마다 clean 학습 경로 하나를 둔다. 분류 2조건에서 각각 200에포크, 생성 5조건에서 각각 2,048업데이트를 수행해 대조군은 총 7개다. 한 조건의 30개 후보 중 학습형 20개는 C₀에서 독립적으로 학습하고 모두 같은 C_T와 품질을 비교한다. 직접 삽입형 10개는 그 C_T에서 각각 출발한다. clean 검증 정확도(분류 5,000장) 또는 검증 시드의 clean RGB(생성 1,000장)도 같은 30개 비교에서 공유한다. `clean/terminal.pt`가 있으면 재개 시 과제 학습을 건너뛰고, `clean/ready.json`이 있으면 clean 검증도 건너뛴다. 학습 중 중단되면 마지막으로 저장한 옵티마이저 상태와 업데이트부터 이어간다. `status --clean --verify`로 각 조건의 단일 종료 파일과 방법 간 참조 일치를 확인할 수 있다.

선정 후 원래 도메인 테스트에서도 같은 C_T·테스트 분할·시드·샘플러에 대한 clean 예측 또는 RGB를 조건별로 한 번 계산해 공유한다. 삽입 직후의 W_T·복호기·메시지가 같으면 저장한 종료 비트열과 BER를 사용한다. 이후 가지치기·양자화·새 도메인 FT는 clean 입력 가중치, 변형 범위와 수준, 학습 조건과 난수가 모두 동일한 비교에서 같은 clean 산출물을 재사용한다. 각 W에 적용한 변형의 가중치와 판독은 해당 W에서 평가한다.

**다른 서버에서 실행.** 서버별 데이터 루트, Python 환경, 결과 폴더 및 GPU 선택 방법은 [저장소 실행 안내](../README.md)에 있다. 조건별 워커는 공통 대조군과 clean 검증이 준비되면 방법별 다섯 강도를 계산한다. 한 조건에서 같은 방법을 중복 실행하지 않도록 파일 잠금을 사용한다. 기본 저장 간격은 분류 702회, 생성 128회다. 같은 환경과 결과 폴더에서 다시 실행하면 완료한 후보를 건너뛰고 마지막으로 저장한 업데이트에서 이어간다.

출력 경로의 `<조건>/clean/terminal.pt`에 C_T, `<조건>/clean/validation/`에 대조군 검증 자료, `<조건>/<방법>/assets/decoder.pt`에 다섯 강도의 공통 키·복호 자료가 있다. 생성 조건의 `training_inputs.json`은 이미지 경로·클래스 대응과 2,048회 업데이트의 배치 순번을 보관한다. SiT는 각 조건의 `native_flow_inputs/`에 공통 VAE 학습 입력을 저장한다(조건당 약 2 GiB). 병렬 워커가 공유하는 ImageNet·Caltech256 중앙 자르기 결과는 출력 경로 옆의 `<출력 디렉터리명>.parallel/source_pixels/`에 있다. StyleSwin의 공통 훈련 RGB는 해당 조건의 `ffhq_training_rgb256/`에 있다. `candidate_1`부터 `candidate_5`는 강도 오름차순이다. 각 폴더의 `terminal.pt`, `readout.json`, `result.json`은 각각 W_T, 복호 상태·오류 수·BER, 대조군·복호 자료의 참조와 품질을 포함한 후보 기록이다. 생성 후보의 `validation/`에는 시드별로 완료한 쌍의 지표가 누적되어 재개할 때 남은 쌍부터 계산한다. `candidates.csv`는 완료한 후보 전부, `selected.csv`와 `selection.json`은 전체 42개 조합의 진행 상태와 선정 결과를 담는다. 다섯 결과가 모일 때까지 `pending`, 전부 비정상이면 `selection_failure`, 유효한 종료값으로 선정하면 `selected`다. `selection.json`의 W_T·C_T·복호 자료에는 경로와 SHA-256이 있어 후속 실험에서 같은 파일을 읽을 수 있다. `report --verify-artifacts`로 참조 파일들의 전체 SHA-256을 재확인할 수 있다. [실행 방법](README.md) · [실행 설정](config/STRENGTH_TRAINING.json)

현재 기록한 값은 사전 설계와 검증용 점검값이다. 본실험의 선정 강도와 검증 품질은 210개 후보 실행을 통해 측정한다. 선정 후 테스트·가지치기·양자화·새 도메인 FT는 6~7절의 절차를 따르며, ArtBench 훈련·검증 사진 ID와 모델별 FT 설정·공통 종료 시점은 해당 FT 전에 확정한다.
