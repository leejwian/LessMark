## 분류 백본의 저에너지 방향 점검 · 원본 C₀

아래 결과에서 MobileNetV3-Large(폭 1.6)의 삽입·복호 위치는 마지막 역잔차 블록의 1×1 투영층 `features.15.block.3.0.weight`(256 × 1,536 × 1 × 1)이고, ResNet18은 마지막 잔차 블록의 두 번째 합성곱 `layer4.1.conv2.weight`(512 × 512 × 3 × 3)이다. 각 모델의 세 방향은 모두 이 가중치에서 비교했다. [실험 2 삽입층과 선정 근거](../EXPERIMENT_DESIGN_KO.md#section-4) · [모델별 가중치 설정](../config/NEXT_EXPERIMENT_DESIGN.json)

두 CIFAR-100 원본 체크포인트에서 모델별 등록 훈련 사진 16,384장(802,816패치)으로 삽입 방향을 계산했다. 같은 가중치에 ID 292의 256비트를 같은 출력 방향과 α=0.2로 삽입하고, 기저만 바꿔 비교했다. 저에너지·고에너지는 각각 입력 패치 2차 모멘트의 가장 작은·가장 큰 고유값에 대응하는 256개 방향이다. 무작위는 시드 20261125에서 뽑은 직교 기저 한 개다. 여섯 경우 모두 실제 가중치 변화의 프로베니우스 노름은 반올림해 3.2였고, 삽입 직후 비트 오류는 0/256이었다.

| 모델 | 방향 | 검증 합성곱 출력 MSE | 검증 로짓 MSE | 원본과 다른 예측 / 5,000장 | 검증 top-1 |
| --- | --- | ---: | ---: | ---: | ---: |
| MobileNetV3-Large | 저에너지 | 3.49×10⁻¹¹ | 1.29×10⁻⁸ | 0 | 62.82% |
| | 무작위 | 5.33×10⁻⁵ | 0.0171 | 48 | 62.98% |
| | 고에너지 | 3.28×10⁻⁴ | 0.205 | 249 | 63.24% |
| ResNet18 | 저에너지 | 1.48×10⁻⁶ | 4.93×10⁻⁵ | 3 | 75.90% |
| | 무작위 | 3.03×10⁻⁵ | 0.0122 | 39 | 75.86% |
| | 고에너지 | 7.54×10⁻⁴ | 0.264 | 202 | 75.64% |

모든 지표는 기저 계산에 사용하지 않은 같은 검증 사진 5,000장에서 측정했다. 합성곱 MSE는 원본과 워터마크 모델의 BN 직전 출력을 위치·채널·사진에 걸쳐 평균한 제곱차다. 로짓 MSE는 최종 100개 클래스 점수의 제곱차를 평균한 값이다. 원본 top-1은 MobileNet 62.82%(3,141장), ResNet18 75.88%(3,794장)였다. 두 모델에서 저에너지 방향이 원본의 출력과 예측을 가장 가깝게 보존했다. 정답률의 순위는 다를 수 있다. 이 점검에는 추가 200에포크 전의 C₀를 사용했다. C_T에서의 강도 선정과 전층 FT 후 BER는 본실험에서 평가한다. [MobileNet 측정 원자료](classifier_backbone_c0_audit/mobilenet_v3_large_w1p6_cifar100.json) · [ResNet18 측정 원자료](classifier_backbone_c0_audit/resnet18_cifar100.json) · [점검 실행 코드](classifier_backbone_c0_audit/check.py)

## 본실험 기록 항목

GPU별 진행 상태와 로그 확인 방법은 [서버 실행 안내](../../README.md)에 있다.

`--output` 경로에서 `plan.json`은 고정 강도표·코드 식별자와 학습 설정을 담는다. 대표강도·배율·출처는 [42개 조합의 강도표](../config/FIVE_STRENGTH_CANDIDATES_REVIEW.csv)에서 각 후보 순번과 대응한다. `candidates.csv`는 완료한 모든 후보의 대표강도·배율·실제 강도·업데이트 수·복호 상태·오류 수·BER·검증 품질, `selected.csv`는 42개 조합의 진행 상태와 최종 선정값을 담는다. `selection.json`에서 선정한 W_T·C_T·복호 자료의 경로·크기·SHA-256을 확인할 수 있다. [실행 및 재개 명령](../README.md#강도-선정-실행)

| 출력 경로 내 위치 | 내용 |

**210개 후보의 최종 기록**에는 모델·데이터셋 조건(7개), 방법(6개), 대표강도 s₀와 그 출처, 배율(¼·½·1·2·4), 실제 강도, 실제 업데이트 수를 남긴다. 모든 후보에서 같은 BIBD 기반 수신자 ID 292 메시지(0·1 각 128개)의 복호 상태, 정상 판독 시 오류 비트 수·BER, 대응 clean 대조군 C_T 대비 검증 품질을 기록한다. 학습량 T는 분류 추가 200에포크(140,400업데이트), 생성 2,048업데이트다. 각 W_T·C_T를 같은 출발 원본 C₀에 연결한다. C_T는 원래 과제 손실만으로 T까지 학습한 대조군이다. 학습형은 원본에 워터마크 항을 더해 T까지 학습하고, 직접 삽입형은 C_T의 복사본에 신호를 더해 추가 업데이트 없이 평가한다. LessMark는 삽입층 이름과 형태, 삽입 직전 C_T의 해당 가중치·기저·출력 방향을 기록해 모든 변형 후 판독에 사용한다. 두 분류기에서는 백본 합성곱에서 얻은 이 정보에 복호 결과를 연결하고, FT 기록에는 분류 헤드의 처리와 백본 갱신 범위를 명시한다.

**42개 조합별 선정 기록**에는 정상 256비트를 반환한 후보 중 최저 BER와 그 강도를 남긴다. 동률이면 그중 가장 큰 강도를 택하며 최저 BER가 0보다 커도 선정한다. 유효한 판독이 없으면 조합을 미선정으로 기록하고 후속 평가 칸에 사유를 남긴다. 실제 선정 수와 전체 조합 수(42)를 함께 보고한다. 품질은 모든 후보에서 측정해 별도 열에 보고한다. [선정 규칙](../EXPERIMENT_DESIGN_KO.md#section-5)

**선정된 각 W_T·C_T 쌍**에는 삽입 직후의 원래 도메인 테스트와 다음 독립 변형별 테스트를 연결한다. 각 변형·수준은 동일한 삽입 직후 쌍의 새 복사본에서 시작한다.

| 평가 | 결과에 연결할 설정 |
| --- | --- |
| 가지치기 | 30%, 70% 각각의 대상 가중치·제거 수와 변형 후 W·C 식별자 |
| 양자화·역양자화 | 8비트, 4비트 각각의 대상 가중치·텐서별 스케일과 변형 후 W·C 식별자 |
| 새 도메인 FT | 분류는 FGVC-Aircraft, 생성은 ArtBench-10. 두 모델 모두 워터마크 항을 끄고 적용한 훈련 사진·배치 순서·업데이트 수·최종 FT 시점. StyleSwin은 생성기·판별기 상태와 각각의 업데이트 수도 보관 |

삽입 직후와 각 변형 후에 해당 W의 복호 상태와 유효한 256비트의 오류 수·BER를 기록한다. 같은 처리를 받은 W와 C의 분류 top-1 정확도 또는 생성 RGB 1,000쌍의 평균 MSE·SSIM을 함께 보고한다. 변형 후 결과는 최초 선정 강도에 연결한다. [강건성 평가](../EXPERIMENT_DESIGN_KO.md#section-6) · [평가와 집계](../EXPERIMENT_DESIGN_KO.md#section-7)
